Node.js

Runtime
JS Runtime

What is Node.js?

Created in 2009

By Ryan Dahl, built on top of the Chrome V8 engine.

Runs outside the browser

Lets you execute JavaScript anywhere, not just in a browser.

Full-stack JavaScript

Write your whole stack, front and back, in one language.

Event-driven & non-blocking

A single-threaded event loop handles concurrent requests.

Comes with npm

A built-in package manager for the entire ecosystem.

Open source & fast

Cross-platform, free to use, and efficient by design.

Source: github.com/nodejs/node · Download: nodejs.org

Runtime
Package Manager

What is npm?

  • Node.js's package manager, bundled in by default.
  • Manages dependencies across your Node.js projects.
  • Lets you install open-source packages with ease.
  • Simplifies adding functionality to your apps.
  • Handles version control so packages stay consistent.

Structuring The API

Controllers, routes, middleware

  • Controllers: modules or functions that handle the business logic for specific API endpoints.
  • Routes: the HTTP methods clients use to interact with the API.
  • Middleware: functions with access to the request and response objects, for processing before the final handler.

Firebase

Backend
What Is Firebase

Not a database — a platform

Firebase is a collection of backend cloud computing services by Google, with a free tier to try things out. It offers, among others:

Databases Authentication Storage Hosting Compute units Analytics
Backend
The Database

What is Cloud Firestore?

NoSQL

A cloud database using a collection/document structure.

Flexible & hierarchical

Store data however your app needs to shape it.

SDKs included

Integrates with web and mobile out of the box.

Realtime updates

Clients stay in sync as data changes.

Offline support

Keeps working when connectivity drops.

Scales automatically

No capacity planning required.
